## ⚠️ 先读这一页：本次部署能到什么程度

动手前必须知道的一件事，否则会白忙一场：

**这套代码的 MySQL 持久化层还没实现。**

| 事实                           | 证据                                        | 后果                       |
| ---------------------------- | ----------------------------------------- | ------------------------ |
| `DB_MODE=mysql` 分支直接抛错"尚未交付" | `apps/server/src/core/repo.factory.ts:22` | 配了 MySQL 也连不上            |
| 生产环境禁止 `DB_MODE=memory`      | `apps/server/src/main.ts:10`              | `NODE_ENV=production` 必崩 |
| 唯一能跑的是内存模式                   | 实测 `/api/health` 返回 `"dbMode":"memory"`   | **重启服务 = 数据全清空**         |

**这两个条件叠加成一个死锁：`NODE_ENV=production` 时，服务 100% 起不来。**

```
NODE_ENV=production + DB_MODE=memory  →  抛错「生产环境禁止 DB_MODE=memory」
NODE_ENV=production + DB_MODE=mysql   →  抛错「DB_MODE=mysql 尚未交付」
NODE_ENV 不设      + DB_MODE=memory   →  ✅ 正常启动（实测通过）
```

所以本次部署的定位是：**演示 / 验收 UI / 过审截图**。不能拿来真正营业 —— 重启一次，商品、订单、余额全没了。

> 想正式用，得先把 Prisma 仓储层补上（`repo.factory.ts` 里那条 TODO）。那是另一个工作量，本文档不涉及。

另外，项目自带的部署文档 `deploy/baota/README.md` 里有**三处与当前代码不符**，照抄会失败，已在本文档纠正：

| 原文档写的                       | 实际情况                               |
| --------------------------- | ---------------------------------- |
| `pm2 start dist/worker.js`  | **没有 worker 这个入口**，启动必失败           |
| `npx prisma migrate deploy` | prisma 依赖没装、也没有 migrations 目录，必然报错 |
| 装 MySQL 8 / Redis 7         | 当前代码**一个都没用到**，白装                  |

## 第 5 步：配置环境变量（**最关键的一步**）

创建 `/www/wwwroot/snack/apps/server/.env`：

宝塔 → 文件 → 进入 `/www/wwwroot/snack/apps/server` → **新建文件** `.env`，内容如下：

```ini
PORT=3000
DB_MODE=memory

# ↓↓↓ 这三行一个字都不要改，改了服务就起不来 ↓↓↓
# NODE_ENV 必须不设或设为 development —— 设为 production 会启动失败
NODE_ENV=development

# 换掉下面两个（用第 0 步生成的随机串）
JWT_SECRET=<第0步生成的第1个串>
PLATFORM_ADMIN_KEY=<第0步生成的第2个串>
SECRETS_MASTER_KEY=<再生成一串，和上面两个都不同>

# 微信小程序
WECHAT_APPID=<你的小程序AppID>
WECHAT_APPSECRET=<你的小程序AppSecret>

# 演示期这两个开着，否则没法造演示数据、没法模拟支付
WECHAT_ALLOW_INSECURE_OPENID=true
DEV_PAY_SIMULATE=true

LOG_LEVEL=info
```

设权限（终端执行）：

```bash
chmod 600 /www/wwwroot/snack/apps/server/.env
```

### 🔴 安全红线（公网部署必须看）

因为 `NODE_ENV` 不能设成 production，那两个"生产禁止回落默认值"的保护也就没生效。所以**这三行绝对不能漏配**：

| 变量                             | 漏配的后果                               |
| ------------------------------ | ----------------------------------- |
| `JWT_SECRET`                   | 任何人可自己签发店主令牌 → 改价、改库存、看全部学生的房间号和手机号 |
| `PLATFORM_ADMIN_KEY`           | 平台后台全线失守 → 可建租户、充值、停用任意店铺           |
| `WECHAT_ALLOW_INSECURE_OPENID` | 开着 = 任何人可冒充任意学生登录（演示期故意开，正式用必须关）    |

> 演示完要正式对外时，至少把 `WECHAT_ALLOW_INSECURE_OPENID` 和 `DEV_PAY_SIMULATE` 改成 `false`。

## 第 6 步：用 PM2 启动

宝塔 → 软件商店 → 装 **PM2管理器**

然后终端执行：

```bash
cd /www/wwwroot/snack/apps/server
pm2 start dist/main.js --name snack-api --cwd /www/wwwroot/snack/apps/server -i 1
pm2 save
```

> **必须是 `-i 1`（单实例）。** 内存模式下数据是存在进程里的，开 2 个实例就是 2 份互不相通的数据 ——  
> 请求打到 A 能看到商品，打到 B 就是空的。

验证：

```bash
curl http://127.0.0.1:3000/api/health
```

应返回（`"dbMode":"memory"`、`"nodeEnv":"development"`）：

```json
{"ok":true,"dbMode":"memory","nodeEnv":"development","pipelineStages":12,...}
```

装开机自启（终端执行，输出的那行命令再复制执行一次）：

```bash
pm2 startup
```

## 第 8 步：配置 Nginx 站点

### 8.1 建站点

宝塔 → **网站** → **添加站点**：

- 域名：填你的已备案域名
- 根目录：`/www/wwwroot/snack/web`
- PHP版本：**纯静态**
- 数据库：不创建

### 8.2 改配置

站点 → **设置** → **配置文件**，整段替换为：

```nginx
server {
    listen 80;
    server_name <你的域名>;
    root /www/wwwroot/snack/web;
    index index.html;
    charset utf-8;
    client_max_body_size 20m;

    # ---- 后端 API ----
    location /api/ {
        proxy_pass http://127.0.0.1:3000;
        proxy_http_version 1.1;
        proxy_set_header Connection "";
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_read_timeout 60s;
    }

    # ---- 兜底路径 /t/{租户编码}/api/ ----
    location ~ ^/t/[^/]+/api/ {
        proxy_pass http://127.0.0.1:3000;
        proxy_http_version 1.1;
        proxy_set_header Connection "";
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    # ---- 平台后台：加 Basic 认证挡一道 ----
    location /platform {
        auth_basic "Restricted";
        auth_basic_user_file /www/server/panel/vhost/nginx/.platform_htpasswd;
        try_files $uri $uri/ /index.html;
    }

    # ---- 商户网页后台（SPA 路由兜底）----
    location / {
        try_files $uri $uri/ /index.html;
    }

    add_header X-Content-Type-Options nosniff always;
    add_header X-Frame-Options DENY always;
}
```

生成平台后台的认证账号（`<平台密码>` 换成自己的）：

```bash
printf "admin:%s\n" "$(openssl passwd -apr1 '<平台密码>')" \
  > /www/server/panel/vhost/nginx/.platform_htpasswd
chmod 600 /www/server/panel/vhost/nginx/.platform_htpasswd
```

点**保存**，Nginx 会自动重载。

### 8.3 申请 SSL

站点 → 设置 → **SSL** → **Let's Encrypt** → 申请 → 打开**强制 HTTPS**

## 出问题先看这里

| 现象                                            | 原因 / 排查                                                                        |
| --------------------------------------------- | ------------------------------------------------------------------------------ |
| 服务起不来，报"生产环境禁止 DB_MODE=memory"                | `.env` 里 `NODE_ENV` 设成了 `production` → 改成 `development`                        |
| 服务起不来，报"DB_MODE=mysql 尚未交付"                   | `.env` 里 `DB_MODE` 设成了 `mysql` → 改成 `memory`                                   |
| 网页能打开但接口 404                                  | Nginx 的 `/api/` 段没生效，或 PM2 没启动 → `pm2 list` + `curl 127.0.0.1:3000/api/health` |
| 网页刷新子页面 404                                   | Nginx `try_files` 没配 → 对照第 8.2 步                                               |
| 小程序提示"店铺未开通"                                  | `manifest.json` 的 AppID 和服务端 `WECHAT_APPID` 不一致                                |
| 小程序请求失败                                       | request 合法域名没配，或没走 https                                                       |
| 重启后数据没了                                       | 正常 —— 内存模式。重跑第 9 步的 seed 脚本                                                    |
| 构建报 `Failed to find './tokens.generated.css'` | 没跑 `npm run tokens:sync`                                                       |

看日志：

```bash
pm2 logs snack-api --lines 100
```
