**判定方式说明**

只会制造**假的安全感** —— 护栏全绿，页面上依然可能是错的。
所以脚本只收"能 100% 判定、零误报"的 5 条，其余人工核对并在这里写明判据与看的位置。

## 三、逐条自查

### AC-01 楼栋牌不得被"改造" ✅（本轮修复）

> 必须：高 44px、圆角 10px（r-md）、brand-500 实心、白字、无阴影无描边。
> 禁止：改成圆角矩形片、加投影、加渐变、改成胶囊。

**改之前**（这是本轮最实质的发现）——楼栋牌在 5 个位置各画一版：

| 位置 | 改之前的高度 | 圆角 |
|---|---|---|
| `pages/shop/home.vue` | `var(--building-chip-h)` = 44px | r-md |
| `pages/shop/category.vue` | 44px | r-md |
| `components/SnCartSheet.vue` | 44px | r-md |
| `pages/order/confirm.vue` | **32px 硬编码** | **r-sm** |
| `pages/address/edit.vue` | **46px 硬编码** | r-md |

三处走 Token、两处写死，高度出现 44 / 32 / 46 三种。AC-01 预言的就是这个：
"一旦各页各画一版，用户就失去了'看到它就知道我在哪栋楼'的条件反射。"

**改之后**

- 唯一实现：`apps/mini/src/components/SnBuildingBar.vue`
  - 高 `var(--building-chip-h)`、圆角 `var(--building-chip-r)`（= `--r-md`）
  - 底色 `var(--building-chip-bg)`（= `--brand-500`）、文字 `var(--building-chip-fg)`（白）
  - 显式写 `box-shadow: none; border: 0 none;` —— 防止后人从别的卡片复制样式时带进来
  - **故意不暴露 size / variant / color**：能改就不叫签名组件了
  - 可变项只有"内容"（name / placeholder）与"能不能点"（pickable / chevron）
  - 解析期的骨架占位也归它管（`loading` prop）—— 以前各页自己画占位容器，
    结果占位容器又是一份独立实现，一样会画歪
- 5 处使用点全部改为 `<SnBuildingBar>`，各自的 `.xxx__bchip` 样式块已删除

**护栏**：`scripts/check-ac.mjs` AC-01 —— 除 `SnBuildingBar.vue` 外，任何 `.vue`
不得引用 `--building-chip-*`；`SnPageSkeleton.vue` 只允许引用尺寸（占位需要），不允许定义底色。

**人工检视看什么**：结算页与地址编辑页现在与首页的楼栋牌**是不是同一块牌子**
（同高、同圆角、同底色、同字号）。

### AC-08 可逆操作不弹确认 ✅（本轮修复）

> 改库存、切楼栋、勾选送达均**立即生效 + 给撤销**。反例：改一次库存弹一次"确定要修改吗"。

**改之前**：`pages-merchant/delivery/index.vue` 的 `onDeliver()` 先弹确认框
（"标记 N 单已送达？…确认后 5 秒内可以撤销"），然后才走延迟提交。
问题是：**既然已经能撤销，再问一遍"确定吗"就是冗余的第二道闸门**，
而且会暗示这一步很危险 —— 实际误标了撤销一下就回来了。

**改之后**：去掉确认，直接 `scheduleDeliver()`（乐观标记 → 5 秒撤销窗口 → 提交；
提交失败还会把行退回待送状态，"不能看起来送了其实没送"）。

其余可逆操作本来就是"立即生效 + 撤销"：

- 改库存：`pages-merchant/stock/quick.vue` 无 `confirm`
- 切楼栋：`composables/useShop.ts` `pickBuilding()` 清空购物车后给 5 秒撤销条
  （`SnUndoBar`），不弹确认
- 移出购物车商品：直接生效

**注意边界**：详情页的单笔送达**保留**确认 —— 那一页点了立刻提交、服务端没有撤回接口，
属于不可逆，按 AC-09 处理（见下）。同一个动作在两页的定性不同，因为可逆性不同。

### AC-13 房间号不出商户库 ✅

> 平台后台任何页面、任何接口响应中都查不到房间号字段（**数据访问层不返回**，非隐藏）。

- `apps/server/src/platform/` 全目录无 `room` 系列字段访问（`[护栏]` AC-13 通过）

  内容恰恰是在警告：**"字段名一改（room_no / roomCode / dorm）过滤就静默失效"**

- 前端还有一张明示卡（见 AC-12）

"前端隐藏"这种反例在本项目里不可能同时满足脚本通过。

### AC-14 时间只有一个真相源 ✅
