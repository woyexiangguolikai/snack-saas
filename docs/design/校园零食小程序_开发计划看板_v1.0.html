01范围裁定：一周硬约束下的三层切分

v0.4 的 D6 明确「不切分，做全量」。本计划不砍功能，但按「能否由 AI 独立完成」把交付物切成三层。

4 端全部 51 页 + 42 条闭环 + 双账本 + 两道闸门 + SKU×楼栋库存矩阵 + 上线流水线 + 20 条 AC 自查 + 演示种子数据 + Docker 一键部署

P1 · AI 可交付（增强项）D8–D10

B4：按楼栋经营看板 / 数据导出 / 送达凭证与争议处理 / 多店员账号与权限 / 拼单优惠券积分评价 / 打印机对接 / 线上自助续费

外部依赖 · AI 无法完成（决定真实上线日）须 D1 即并行启动

小程序注册 + 微信认证（300/年）｜ICP 备案（1–20 工作日）｜微信支付商户号（人脸/打款）｜代码上传密钥 + IP 白名单｜食品服务类目资质｜商户提审与发布

⚠️ 必须先说清：代码一周内可以写完，但「真实上线」一周内不可能完成 —— 卡点是 ICP 备案（1–20 个工作日，主体是商户）与商户号本人办理，不是代码问题。因此本计划把「代码交付日 D7」与「上线日」解耦：D7 交付的是「接上商户凭证即可推送」的完整系统，D8–D10 用体验版 + Mock 支付在真实小程序环境全链路验证。
